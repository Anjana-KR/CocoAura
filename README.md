# CocoAura 🥥✨

Luxury Cold-Pressed Coconut Hair Care — crafted with Kerala botanicals.

## Overview
CocoAura is an interactive, luxury e-commerce experience featuring smooth scroll frame sequences, botanical deep dives, a personalized hair ritual quiz, before/after transformations, and cart management.

## Tech Stack
- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Animations & Effects:** Canvas Confetti, HTML5 Canvas frame scrubbing

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
